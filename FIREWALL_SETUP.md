# Настройка брандмауэра Windows для доступа по IP

## Проблема
Если серверы запущены, но http://192.168.15.237:3000 не открывается из браузера, вероятно блокирует брандмауэр Windows.

## Решение

### Вариант 1: Через PowerShell (от имени администратора)

1. Откройте PowerShell от имени администратора (правой кнопкой мыши → "Запуск от имени администратора")

2. Выполните следующие команды:

```powershell
# Разрешить доступ к веб-серверу (порт 3000)
netsh advfirewall firewall add rule name="Neetrino Web Server" dir=in action=allow protocol=TCP localport=3000

# Разрешить доступ к API серверу (порт 3001)
netsh advfirewall firewall add rule name="Neetrino API Server" dir=in action=allow protocol=TCP localport=3001
```

### Вариант 2: Через графический интерфейс

1. Откройте "Брандмауэр Защитника Windows" (Windows Defender Firewall)
2. Нажмите "Дополнительные параметры"
3. Выберите "Правила для входящих подключений"
4. Нажмите "Создать правило..."
5. Выберите "Для порта"
6. Укажите TCP и порты 3000 и 3001
7. Выберите "Разрешить подключение"
8. Примените правило для всех профилей
9. Назовите правило "Neetrino Platform"

## Проверка

После настройки брандмауэра проверьте доступность:

- Веб-приложение: http://192.168.15.237:3000
- API: http://192.168.15.237:3001
- Swagger: http://192.168.15.237:3001/api/docs

## Статус серверов

Серверы уже запущены и работают:
- ✅ Веб-сервер: порт 3000, слушает на 0.0.0.0
- ✅ API сервер: порт 3001, слушает на 0.0.0.0

Если после настройки брандмауэра проблема сохраняется, проверьте:
1. Запущены ли процессы Node.js (Get-Process node)
2. Слушают ли порты (netstat -ano | findstr ":3000")
3. Правильно ли настроен роутер/сеть
