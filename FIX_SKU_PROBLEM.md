```bash

```

Этот скрипт:
- Найдет все записи без `sku`
- Заполнит `sku` из `metadata.sku` или `metadata.id`
- Пропустит записи, где `sku` уже используется другим товаром

### Шаг 2: Перезапустить импорт данных (опционально)

Если нужно переимпортировать данные с правильным `sku`:

```bash

```

Теперь импорт:

## 📋 Логика работы

### Поиск товара (`demos.service.findOne()`)

1. Если переданная строка похожа на UUID → ищет по `id` (UUID)
2. Если не найдено → ищет по `sku`
3. Если не найдено → ищет по `metadata.sku`
4. Если не найдено → 404

### Каталог

- `search.service` возвращает `id = sku || uuid`
- В каталоге используется `href="/catalog/${demo.id}"` где `demo.id = sku`
- При клике открывается `/catalog/[sku]`

### API роут

- Next.js API роут просто пробрасывает запрос в NestJS
- NestJS `demos.service.findOne()` сам решает, UUID это или SKU
- Никаких лишних fallback'ов
