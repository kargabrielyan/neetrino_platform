# 🌐 Доступ к приложению из локальной сети

## ✅ Настройка завершена!

Ваше приложение теперь доступно для всех устройств в вашей Wi-Fi сети.

## 📱 Адреса для доступа:

- **Веб-приложение:** http://192.168.15.237:3000
- **API сервер:** http://192.168.15.237:3001
- **API документация:** http://192.168.15.237:3001/api/docs

## 🚀 Как запустить:

### Вариант 1: PowerShell (рекомендуется)
```powershell
.\start-local-network.ps1
```

### Вариант 2: Batch файл
```cmd
start-local-network.bat
```

### Вариант 3: Ручной запуск
1. Откройте два терминала
2. В первом терминале:
   ```bash
   cd apps/api
   set API_HOST=0.0.0.0
   set API_URL=http://192.168.15.237:3001
   npm run dev
   ```
3. Во втором терминале:
   ```bash
   cd apps/web
   set NEXTAUTH_URL=http://192.168.15.237:3000
   npm run dev
   ```

## 📱 Доступ с других устройств:

1. **Убедитесь, что устройство подключено к той же Wi-Fi сети**
2. **Откройте браузер на устройстве**
3. **Перейдите по адресу:** `http://192.168.15.237:3000`

## 🛠️ Устранение проблем:

### Если приложение не открывается с других устройств:

1. **Проверьте брандмауэр Windows:**
   - Откройте "Брандмауэр Windows"
   - Разрешите Node.js через брандмауэр

2. **Проверьте, что порты открыты:**
   ```cmd
   netstat -an | findstr ":300"
   ```
   Должны быть строки с `0.0.0.0:3000` и `0.0.0.0:3001`

3. **Проверьте IP адрес:**
   ```cmd
   ipconfig
   ```
   Убедитесь, что IP адрес Wi-Fi адаптера `192.168.15.237`

### Если IP адрес изменился:

1. Обновите IP в файлах:
   - `start-local-network.ps1`
   - `start-local-network.bat`
   - `env.local.example`

2. Или установите переменные окружения вручную

## 🔒 Безопасность:

- Приложение доступно только в вашей локальной сети
- Внешний интернет не имеет доступа к приложению
- Для внешнего доступа потребуется настройка роутера и проброс портов
